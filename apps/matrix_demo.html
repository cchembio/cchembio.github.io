Matrizen als lineare Abbildungen

Jede 2×2-Matrix A beschreibt eine lineare Abbildung der Ebene. Die erste Spalte ist das Bild von e₁ = (1, 0), die zweite Spalte das Bild von e₂ = (0, 1). Das transformierte Gitter zeigt, wie A den gesamten Raum verformt. Die Determinante gibt an, um welchen (vorzeichenbehafteten) Faktor Flächen skaliert werden.

[
1.0 0.0 0.0 1.0
]
a 1.0
c 0.0
b 0.0
d 1.0
